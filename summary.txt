How to use
Source the workspace

$ source ~/colcon_ws/install/local_setup.bash

Run orbslam mode, which you want.
This repository only support MONO, STEREO, RGBD, STEREO-INERTIAL mode now.
You can find vocabulary file and config file in here. (e.g. orbslam3_ros2/vocabulary/ORBvoc.txt, orbslam3_ros2/config/monocular/TUM1.yaml for monocular SLAM).

MONO mode
$ ros2 run orbslam3 mono PATH_TO_VOCABULARY PATH_TO_YAML_CONFIG_FILE

example：

T1:
ros2 run realsense2_camera realsense2_camera_node

or
ros2 launch realsense2_camera rs_launch.py

T2:

ros2 run orbslam3 mono src/orbslam3_ros2/vocabulary/ORBvoc.txt src/orbslam3_ros2/config/monocular/RealSense_D435i.yaml



STEREO mode
$ ros2 run orbslam3 stereo PATH_TO_VOCABULARY PATH_TO_YAML_CONFIG_FILE BOOL_RECTIFY

T1:
ros2 launch realsense2_camera rs_launch.py enable_infra1:=true enable_infra2:=true enable_accel:=true enable_gyro:=true unite_imu_method:=2 infra_width:=640 infra_height:=480

T2:
ros2 run orbslam3 stereo src/orbslam3_ros2/vocabulary/ORBvoc.txt src/orbslam3_ros2/config/stereo/RealSense_D435i.yaml false


RGBD mode
$ ros2 run orbslam3 rgbd PATH_TO_VOCABULARY PATH_TO_YAML_CONFIG_FILE

T1:
ros2 launch realsense2_camera rs_launch.py

T2:
ros2 run orbslam3 rgbd src/orbslam3_ros2/vocabulary/ORBvoc.txt src/orbslam3_ros2/config/rgb-d/RealSense_D435i.yaml

STEREO-INERTIAL mode
$ ros2 run orbslam3 stereo-inertial PATH_TO_VOCABULARY PATH_TO_YAML_CONFIG_FILE BOOL_RECTIFY [BOOL_EQUALIZE]

example:

T1:
ros2 launch realsense2_camera rs_launch.py enable_infra1:=true enable_infra2:=true enable_accel:=true enable_gyro:=true unite_imu_method:=2 infra_width:=640 infra_height:=480

T2:
ros2 run orbslam3 stereo-inertial src/orbslam3_ros2/vocabulary/ORBvoc.txt src/orbslam3_ros2/config/stereo-inertial/RealSense_D435i.yaml false
